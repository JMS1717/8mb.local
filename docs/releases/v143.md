# 8mb.local v143.0.0.0

## Platform support

- Windows x64 and native Windows ARM64 EXE, installer, and MSIX packages.
- Native Apple Silicon macOS app/DMG using Cocoa and VideoToolbox.
- Native Linux Docker images for amd64 and arm64 with a guarded combined
  multi-architecture publishing workflow.
- Standalone Android 8+ Kotlin/Compose app using Media3 and MediaCodec.

## Hardware encoding

The shared runtime now discovers and probes Windows Media Foundation and Apple
VideoToolbox in addition to NVENC, QSV, AMF, and VAAPI. Detection is based on a
real encoder start, not an encoder-list match. Job construction uses the same
device path tested at startup and keeps the existing controlled CPU fallback.

The Android app uses an input-surface configure/start probe, prioritizes working
hardware encoders, pins one encoder per export attempt, and records Media3's
actual encoder name. A target-size overshoot above two percent receives one
bounded bitrate-adjusted retry.

## Validation status

Automated tests cover codec mapping/detection, API and UI visibility, platform
configuration, Android bitrate planning, version synchronization, and package
assembly. Native architecture CI builds run on matching ARM64 runners rather
than emulation.

Physical Apple Silicon, Windows ARM64, and Android hardware smoke results are
not claimed until the included physical-device scripts/workflows run on those
devices. Those checks assert actual encoder telemetry so a software fallback
cannot be mistaken for hardware acceleration.
