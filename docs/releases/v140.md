# 8mb.local v140.0.0.0 — Local Release Changelog

Status: draft release. Not published. No Docker push or Store submission was created.

## Highlights

- Added a shared `VERSION` source and synchronized the UI, backend API, Windows metadata, installer, MSIX, Docker metadata, workflows, and artifact naming for v140.
- Added the local release workflow for producing the portable Windows EXE, installer EXE, MSIX, Docker image/archive, checksums, manifest, and test report without GitHub Actions.
- Improved codec discovery and persistence so hardware detection does not overwrite saved visibility or selections, while CPU fallback codecs remain available.
- Preserved profile values during editing and switching, including FPS caps, and repaired default-profile deletion selection behavior.
- Added dynamic media-storage admission: `auto` prefers RAM-backed temporary storage when the live budget allows and falls back to disk; `memory` requires a safe fit; `disk` stays disk-backed.
- Raised the configurable Docker shared-memory and media-memory defaults to 10 GB. This is a maximum/admission budget, not a reservation of 10 GB for every user or a guarantee of RAM-only storage.
- Added Windows RAM-preferred temporary-file behavior using the normal Windows cache and `FILE_ATTRIBUTE_TEMPORARY` where available, while retaining normal filesystem paths for FFmpeg.
- Added transient upload cleanup after success, retry/fallback, cancellation, and failure, plus recovery cleanup for stale temporary files.
- Added automatic history pruning for expired and orphaned entries using timezone-aware UTC timestamps.
- Improved HEVC MP4 compatibility by emitting the `hvc1` sample-entry tag so Apple/mobile players can identify the stream correctly.
- Moved Support the Project to the top of Settings and left it expanded by default; Folder Watch remains at the bottom and collapsed by default.
